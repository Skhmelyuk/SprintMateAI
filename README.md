# SprintMateAI

SprintMateAI — це легкий React-додаток для планування спринту або хакатону. Він допомагає перетворити ідею проєкту на структурований план із фазами, завданнями та оцінкою часу, щоб команда швидше переходила від концепції до реалізації.

## Основні функції

- Створення плану спринту за назвою проєкту та навантаженням
- Вибір формату спринту: індивідуальний або командний
- Встановлення загальної кількості годин для спринту
- Генерація структурованої дорожньої карти проєкту з фазами та завданнями
- Позначення завдань як виконаних під час спринту
- Збереження налаштувань додатку локально в браузері
- Підтримка генерації через OpenRouter та режим макету для демо

## Локальний запуск

1. Встановіть залежності:
   npm install
2. Запустіть сервер розробки:
   npm run dev
3. Зберіть production-бандл:
   npm run build
